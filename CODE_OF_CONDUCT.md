# Code of Conduct

We want this project to be friendly and useful for everyone, especially students.

## Expected behaviour
- Be kind and patient. Many contributors are learning.
- Respect different opinions, experience levels and backgrounds.
- Give feedback on the work, not the person.
- Assume good intent and ask when something is unclear.

## Not acceptable
- Harassment, insults, discrimination or personal attacks
- Spam, trolling or off-topic promotion
- Sharing someone's private information
- Anything else that makes others feel unsafe or unwelcome

## Enforcement
Maintainers may edit or remove comments, close issues, and block people who break these rules. To report a problem, contact the maintainer through the email on their GitHub profile.

This Code of Conduct applies in issues, pull requests, discussions and any other project space.
