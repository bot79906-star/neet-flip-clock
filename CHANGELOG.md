# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [4.4.0] - Sync
### Added
- Chrome and Edge stay in step (settings, dates, timer, history) through one private GitHub gist.
- Calibrated plan ruler with month, quarter and year marks and weekly lines.
- About 70 motivation lines, shown in the side columns, countdown, deep focus, reminder and notifications.

### Changed
- "At desk" is now device-on time, counted every 30 seconds and paused while the device sleeps.
- Default exam date is 1 May 2028.

### Removed
- Study-statistics lines removed everywhere.

## [4.3.0] - Deep Focus
### Added
- Immersive full-screen timer (`D` key).
- Subject tags with time logged per subject, and a subject-coloured week chart.
- Effects level (Full / Light / Off).
- Backup export and import.

## [4.2.0] - Clean Flip
### Changed
- Flip no longer overshoots or pushes the card down; faster seconds flip.
- Percentages removed; day-grid hover text moved out of the way.

## [4.1.0] - Time Rail
### Added
- Always-visible bar showing your position in the plan.
- Day-by-day grid in Journey.
- Rotating discipline lines, embers, bold-only type, and a layout that fits short windows.

## [4.0.0] - Focus
### Added
- Pomodoro focus timer inside the flip clock.
- Today's study time, reference dates, settings sheet.
- Reminder interval, toolbar badge and notifications.
